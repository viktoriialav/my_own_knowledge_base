# Команды
___

## Изменение директории

- `cd [path]` - перемещает в каталог, указанный в `[path]`
- `cd` - перемещает в домашний каталог пользователя
- `cd ~` - перемещает в домашний каталог пользователя (`~` - домашний каталог пользователя)
- `cd ..` - перемещает на один уровень вверх в иерархии каталогов
- `cd -` - перемещает в каталог, в котором вы были до этого (в предыдущий каталог)
- `cd /` - перемещает в корневой каталог системы

---
## Получение информации

### Путь к каталогу
- `pwd` - выводит полный путь к текущему каталогу

### Содержимое каталога
- `ls` - отображает файлы и каталоги в текущем каталоге
- `ls -a` - отображает все файлы, включая скрытые, начинающиеся с '.'
- `ls -h` - отображает каталоги и файлы с указанием расширения файла
- `ls -l` - отображает детальный список файлов и каталогов, включая права доступа, кол-во ссылок, владельца, группу, 
размер и время последнего изменения
- `ls -s` - отображает все каталоги и файлы с указанием их размера
- `ls -S` - сортировка по размеру файла
- `ls -t` - сортировка по времени и дате
- `ls -X` - сортировка по имени расширения

### Вывод содержимого файла на экран
- `cat [<options>] [file_name_1] ... [file_name_n]` - отображает содержимое файла/файлов
Опции `[<options>]`:
    - `-n` - добавляется нумерация строк
    - `-T` - отображает табуляцию как `^I`
    - `-e` - отображает невидимый символ окончания строки

## Манипуляции с файлами и каталогами

### Создание нового файла

- `touch [file_name]` - создает новый пустой файл или обновляет временные метки существующего файла
- `cat > [file_name]` *Press Enter* `[text]` *Press Ctrl+D to save the file* - создание файла c содержимым `[text]` или 
пустой файл, либо перезапись существующего файла
- `> [file_name]` - создание пустого файла или перезапись существующего файла (очистка)
- `echo > [file_name]` - создание пустого файла или перезапись существующего файла (очистка)
- `echo [string] > [file_name]` - создает новый файл со строкой `[string]`, указанной в аргументе команды `echo`, или 
перезаписывает содержимое файла
- `printf [string] > [file_name]` - создает новый файл со строкой `[string]` (учитывая символы форматирования, 
например, `\n`), указанной в аргументе команды `printf`, или перезаписывает содержимое файла.

### Создание новой директории
- `mkdir [directory_name]` - создание нового каталога с именем `[directory_name]`


### Удаление файлов

- `unlink [file_name]` -  удаление одного файла
- `rm [<options>] [file_name]` - удаление файла с именем `[file_name]`. 
Если у вас нет прав на запись в родительский каталог, вы получите ошибку «Операция запрещена».
Если файл не защищен от записи, он будет удален без уведомления. В случае успеха команда не производит никакого вывода 
и возвращает ноль.
При удалении файлов, защищенных от записи, команда запросит подтверждение.  
Опции `[<options>]`:
    - `-f` - никогда не запрашивать пользователя и игнорировать несуществующие файлы и аргументы
    - `-v` - для получения информации о том, что удаляется
    - `-i` - запрашивает пользователя для каждого заданного файла перед удалением
    - `-I` - запрашивает пользователя один раз пере удалением более трех файлов или при рекурсивном удалении 
  (менее навязчиво, чем `-i`)

- `rm [<options>] [file_name_1] ... [file_name_n]` - удаление n файлов (файлы перечисляются без запятых). 
- `rm *.png` - удаление всех файлов с расширением `.png` в текущем каталоге

###  Удаление каталогов

- `rmdir [empty_directory_name]` - удаление пустой директории с именем `[empty_directory_name]`    
- `rm -d [dir_name_1] ... [dir_name_n]` - удаление одного или нескольких пустых каталогов (каталоги перечисляются
без запятых). Данная команда идентичная команде `rmdir`.
- `rm -r [dir_name_1] ... [dir_name_n]` - рекурсивное удаление непустых каталогов и всех файлов в них.


### Перемещение и переименование файлов

- `mv [<options>] [source] [destination]` - перемещение файла или каталога `[source]` в `[destination]` или 
переименование файла или каталога `[source]` в `[destination]`.   
Опции `[<options>]`:
    - `-f` - принудительная перезапись или переименование файла
    - `-n` - отключает перезапись уже существующих объектов
    - `-i` - запрашивает пользователя для каждого заданного файла перед перемещением или переименованием
    - `-v` - отображает сведения о каждом элементе во время обработки команды
    - `-b` - создает копию файлов, которые были перемещены или перезаписаны
- `mv [<options>] [source_1] ... [source_n] [destination]` - перемещение файлов или каталогов
`[source_1]`, ..., `[sourse_n]` в `[destination]`
- `mv -t [destination] [source]/*` - перемещает все файлы из `[source]` в указанную директорию
`[destination]` (пример: `mv -t /f/folder_2 /f/folder_1/*`)

### Копирование файлов и каталогов

- `cp [<options>] [source_file] [destination_file]` - копирует первый файл `[source_file]` во второй
`[destination_file]`. Если файл не существует, команда создает его.
- `cp [<options>] [source_1] .. [sourse_n]  [destination_directory]` - файлы и каталоги `[source_1] .. [sourse_n]` 
перемещаются в каталог `[destination_directory]`.
- `cp [<options>] [source_directory] [destination_directory]` - копирует первый каталог `[source_directory]`
во второй `[destination_directory]`.  
Опции `[<options>]`:
    - `-f` - принудительная копирование
    - `-n` - отключает перезапись уже существующих объектов (по умолчанию, если целевой файл существует, он перезаписывается)
    - `-i` - запрашивает пользователя для каждого заданного файла перед каждой операцией
    - `-v` - отображает сведения о каждом элементе во время обработки команды
    - `-R` / `-r` - все файлы и подкаталоги из источника в целевой каталог
    - `-t` / `--target-directory=DIRECTORY` - копирует все файлы/каталоги в целевой каталог
    - `-T` / `--no-target-directory` - рассматривает целевой каталог как обычный файл
- `cp -RT [source_directory] [destination_directory]` - копирует только файлы и подкаталоги, но не 
исходный каталог, в `[destination_directory]`
- `cp -RT [source_directory]/* [destination_directory]/` - копирует только файлы и подкаталоги, но не 
исходный каталог, в `[destination_directory]` (НО! не копирует скрытые файлы и каталоги)

### Перенаправление и добавление содержимого файла, объединение файлов
- `cat [file_name_1] > [file_name_2]` - копирует содержимое файла `[file_name_1]` в файл `[file_name_2]`. 
Если файл `[file_name_2]` не существует, команда создаст его. В противном случае она перезапишет файл.
- `cat [file_name_1] >> [file_name_2]` - добавляет содержимое файла `[file_name_1]` в файл `[file_name_2]`
- `cat [file_name_1] .. [file_name_n] > [file_name_result]` - записывает содержимое двух и более файлов 
`[file_name_1] .. [file_name_n]` в новый файл `[file_name_result]`. Если `[file_name_result]` файл не существует, 
то команда создаст его. В противном случае она перезапишет файл.
- `cat [file_name_1] .. [file_name_n] >> [file_name_result]` - добавляет содержимое двух и более файлов 
`[file_name_1] .. [file_name_n]` в файл `[file_name_result]`. Если `[file_name_result]` файл не существует, 
то команда создаст его.
