# Команды
___

## Получение информации
___

### Получение информации о команде

- `man [command]`
- `[command] --help`

### Информация об активных процессах
- `ps` - показывает процессы, запущенные в текущем терминале
- `ps aux` - показывает все запущенные процессы с дополнительной информацией

### Путь к каталогу
- `pwd` - выводит полный путь к текущему каталогу (аналогично `echo $PWD`)

### Содержимое каталога
- `ls` - отображает файлы и каталоги в текущем каталоге
- `ls -a` - отображает все файлы, включая скрытые, начинающиеся с '.'
- `ls -h` - отображает каталоги и файлы с указанием расширения файла
- `ls -l` - отображает детальный список файлов и каталогов, включая права доступа, кол-во ссылок, владельца, группу, 
размер и время последнего изменения
- `ls -s` - отображает все каталоги и файлы с указанием их размера
- `ls -S` - сортировка по размеру файла
- `ls -t` - сортировка по времени и дате
- `ls -X` - сортировка по имени расширения

Расшифровка вывода команды `ls -l filename.txt`:
```
-rw-r--r-- 12 linuxize users 12.0K Apr  8 20:51 filename.txt
|[-][-][-]-   [------] [---]
| |  |  | |      |       |
| |  |  | |      |       +-----------> 7. Group
| |  |  | |      +-------------------> 6. Owner
| |  |  | +--------------------------> 5. Alternate Access Method
| |  |  +----------------------------> 4. Others Permissions
| |  +-------------------------------> 3. Group Permissions
| +----------------------------------> 2. Owner Permissions
+------------------------------------> 1. File Type
```

### Вывод содержимого файла на экран
- `cat [<options>] [file_name_1] ... [file_name_n]` - отображает содержимое файла/файлов
Опции `[<options>]`:
    - `-n` - добавляется нумерация строк
    - `-T` - отображает табуляцию как `^I`
    - `-e` - отображает невидимый символ окончания строки

## Манипуляции с файлами и каталогами
___

### Изменение директории

- `cd [path]` - перемещает в каталог, указанный в `[path]`
- `cd` - перемещает в домашний каталог пользователя
- `cd ~` - перемещает в домашний каталог пользователя (`~` - домашний каталог пользователя)
- `cd ..` - перемещает на один уровень вверх в иерархии каталогов
- `cd -` - перемещает в каталог, в котором вы были до этого (в предыдущий каталог)
- `cd /` - перемещает в корневой каталог системы

### Создание нового файла

- `touch [file_name]` - создает новый пустой файл или обновляет временные метки существующего файла
- `cat > [file_name]` *Press Enter* `[textЮ]` *Press Ctrl+D to save the file* - создание файла c содержимым `[text]` или 
пустой файл, либо перезапись существующего файла
- `> [file_name]` - создание пустого файла или перезапись существующего файла (очистка)
- `echo > [file_name]` - создание пустого файла или перезапись существующего файла (очистка)
- `echo [string] > [file_name]` - создает новый файл со строкой `[string]`, указанной в аргументе команды `echo`, или 
перезаписывает содержимое файла
- `printf [string] > [file_name]` - создает новый файл со строкой `[string]` (учитывая символы форматирования, 
например, `\n`), указанной в аргументе команды `printf`, или перезаписывает содержимое файла.


### Создание новой директории (каталога)
- `mkdir [directory_name]` - создание нового каталога с именем `[directory_name]`


### Удаление файлов

- `unlink [file_name]` -  удаление одного файла
- `rm [<options>] [file_name]` - удаление файла с именем `[file_name]`. 
Если у вас нет прав на запись в родительский каталог, вы получите ошибку «Операция запрещена».
Если файл не защищен от записи, он будет удален без уведомления. В случае успеха команда не производит никакого вывода 
и возвращает ноль.
При удалении файлов, защищенных от записи, команда запросит подтверждение.  
Опции `[<options>]`:
    - `-f` - никогда не запрашивать пользователя и игнорировать несуществующие файлы и аргументы
    - `-v` - для получения информации о том, что удаляется
    - `-i` - запрашивает пользователя для каждого заданного файла перед удалением
    - `-I` - запрашивает пользователя один раз пере удалением более трех файлов или при рекурсивном удалении 
  (менее навязчиво, чем `-i`)

- `rm [<options>] [file_name_1] ... [file_name_n]` - удаление n файлов (файлы перечисляются без запятых). 

Примеры:
- `rm *.png` - удаление всех файлов с расширением `.png` в текущем каталоге
- `find [dir_name] -name '*.temp' -delete` - находит файлы с расширением `'*.temp'` и удаляет их

###  Удаление каталогов

- `rmdir [empty_directory_name]` - удаление пустой директории с именем `[empty_directory_name]`    
- `rm -d [dir_name_1] ... [dir_name_n]` - удаление одного или нескольких пустых каталогов (каталоги перечисляются
без запятых). Данная команда идентичная команде `rmdir`.
- `rm -r [dir_name_1] ... [dir_name_n]` - рекурсивное удаление непустых каталогов и всех файлов в них.
- `find [dir_name] -type d -delete` - находит в каталоге [dir_name] пустые каталоги и удаляет их 
(удаляет только пустые!)


### Перемещение и переименование файлов

- `mv [<options>] [source] [destination]` - перемещение файла или каталога `[source]` в `[destination]` или 
переименование файла или каталога `[source]` в `[destination]`.   
Опции `[<options>]`:
    - `-f` - принудительная перезапись или переименование файла
    - `-n` - отключает перезапись уже существующих объектов
    - `-i` - запрашивает пользователя для каждого заданного файла перед перемещением или переименованием
    - `-v` - отображает сведения о каждом элементе во время обработки команды
    - `-b` - создает копию файлов, которые были перемещены или перезаписаны
- `mv [<options>] [source_1] ... [source_n] [destination]` - перемещение файлов или каталогов
`[source_1]`, ..., `[sourse_n]` в `[destination]`
- `mv -t [destination] [source]/*` - перемещает все файлы из `[source]` в указанную директорию
`[destination]` (пример: `mv -t /f/folder_2 /f/folder_1/*`)

### Копирование файлов и каталогов

- `cp [<options>] [source_file] [destination_file]` - копирует первый файл `[source_file]` во второй
`[destination_file]`. Если файл не существует, команда создает его.
- `cp [<options>] [source_1] .. [sourse_n]  [destination_directory]` - файлы и каталоги `[source_1] .. [sourse_n]` 
перемещаются в каталог `[destination_directory]`.
- `cp [<options>] [source_directory] [destination_directory]` - копирует первый каталог `[source_directory]`
во второй `[destination_directory]`.  
Опции `[<options>]`:
    - `-f` - принудительная копирование
    - `-n` - отключает перезапись уже существующих объектов (по умолчанию, если целевой файл существует, он перезаписывается)
    - `-i` - запрашивает пользователя для каждого заданного файла перед каждой операцией
    - `-v` - отображает сведения о каждом элементе во время обработки команды
    - `-R` / `-r` - все файлы и подкаталоги из источника в целевой каталог
    - `-t` / `--target-directory=DIRECTORY` - копирует все файлы/каталоги в целевой каталог
    - `-T` / `--no-target-directory` - рассматривает целевой каталог как обычный файл
- `cp -RT [source_directory] [destination_directory]` - копирует только файлы и подкаталоги, но не 
исходный каталог, в `[destination_directory]`
- `cp -RT [source_directory]/* [destination_directory]/` - копирует только файлы и подкаталоги, но не 
исходный каталог, в `[destination_directory]` (НО! не копирует скрытые файлы и каталоги)

### Перенаправление и добавление содержимого файла, объединение файлов
- `cat [file_name_1] > [file_name_2]` - копирует содержимое файла `[file_name_1]` в файл `[file_name_2]`. 
Если файл `[file_name_2]` не существует, команда создаст его. В противном случае она перезапишет файл.
- `cat [file_name_1] >> [file_name_2]` - добавляет содержимое файла `[file_name_1]` в файл `[file_name_2]`
- `cat [file_name_1] .. [file_name_n] > [file_name_result]` - записывает содержимое двух и более файлов 
`[file_name_1] .. [file_name_n]` в новый файл `[file_name_result]`. Если `[file_name_result]` файл не существует, 
то команда создаст его. В противном случае она перезапишет файл.
- `cat [file_name_1] .. [file_name_n] >> [file_name_result]` - добавляет содержимое двух и более файлов 
`[file_name_1] .. [file_name_n]` в файл `[file_name_result]`. Если `[file_name_result]` файл не существует, 
то команда создаст его.

### Просмотр содержимого файла с помощью утилит и файловых редакторов

*less* - утилита для просмотра текстовых файлов, позволяющая прокручивать содержимое в обе стороны и искать текст.  
*nano* - это текстовый редактор для Unix и Unix-подобных систем.  
*vi* - универсальный полноэкранный текстовый редактор в среде UNIX.

- `less [file_name]` - откроет файл для просмотра
- `nano [file_name]` - откроет файл для редактирования в `nano`
- `vi [file_name]` - откроет файл для редактирования в `vi`

Навигация во время просмотра файла с помощью утилиты `less`:

- `Down arrow` , `Enter` , `e` или `j` - перейти на одну строку вперед.
- `Up arrow` , `y` или `k` - перейти на одну строку назад.
- `Space bar` или `f`	Перейти на одну страницу вперед.
- `b`	Перейти на одну страницу назад.
- `/pattern` - ищет подходящие шаблоны.
- `?pattern` - поиск в обратном направлении совпадающих шаблонов.
- `n`	Повторите предыдущий поиск.
- `N`	Повторите предыдущий поиск в обратном направлении.
- `g`	Перейти к первой строке файла.
- `Ng`	Перейти к N-й строке файла.
- `G`	Перейти к последней строке файла.
- `p`	Перейти в начало файла.
- `Np`	Заходим на N процентов в файл.
- `h`	Показать справку.
- `q`	Выход из `less`.

### Поиск файлов

`grep` (Global Regular Expression Print) используется для поиска и вывода строк в файлах, которые соответствуют 
заданному шаблону (обычно регулярному выражению). Чтобы иметь возможность искать файл, пользователь, выполняющий 
команду `grep`, должен иметь доступ для чтения к файлу.

Синтаксис: `grep [<options>] [pattern] [<file_name_1>] .. [<file_name_n>]`

Опции `[<options>]`:
- `-i`- игнорирует регистр символов при поиске.
- `-v`- выводит строки, которые не соответствуют шаблону.
- `-r`- рекурсивный поиск по всем файлам в указанной директории.
- `-n`- выводит номера строк с соответствующими результатами.
- `-c`- подсчитывает количество строк, соответствующих шаблону.
- `-E`- использует расширенные регулярные выражения.


`find` ищет файлы и каталоги в иерархии каталогов на основе заданного пользователем выражения и может выполнять 
указанное пользователем действие для каждого совпадающего файла. Для поиска файлов в каталоге пользователь, вызывающий
команду `find` должен иметь разрешения на чтение в этом каталоге.

Синтаксис: `find [<options>] [<path_1>] .. [<path_n>] [expression]`  

Опции `[<options>]`:
- `-name` - ищет файлы по имени
- `-iname` - ищет файлы по имени без учета регистра
- `-type` - ищет файлы определенного типа
- `-size` - ищет файлы определенного размера
- `-user` - ищет файлы принадлежащие определенному владельцу
- `-group` - ищет файлы принадлежащие определенной группе
- `-perm` - ищет файлы с определенными правами доступа
- `-mtime` - ищет файлы, измененные определенное количество дней назад
- `-exec` - выполняет команду для каждого найденного файла

Для поиска файлов по их типу используйте параметр `-type` и один из следующих дескрипторов, 
чтобы указать тип файла:
- `f` - обычный файл
- `d` - каталог
- `l` - символическая ссылка
- `c` - символьные устройства
- `b` - блочные устройства
- `p` - именованный канал (FIFO)
- `s` - сокет

Примеры:
- `find / -user man1234` - находит все файлы и каталоги, принадлежащие пользователю `man1234`
- `find / -user www-data -type f  -exec chown nginx {}` - находит все файлы, принадлежащие 
пользователю `www-data`, и изменяет владельца совпадающих файлов с `www-data` на `nginx`
- `find . -type f  -name '*.txt'` - находит файлы по расширению

### Изменение прав доступа

`chmod [<options>] [mode][<,mode>] [file_name_1] .. [file_name_n]`

`[mode]` задается в форме `[ugoa]*([-+=]([rwxXst]*|[ugo]))+|[-+=][0-7]+`

Опции `[<options>]`:
- `-R` — рекурсивное изменение прав доступа для каталогов и их содержимого
- `-f` — не выдавать сообщения об ошибке для файлов, чьи права не могут быть изменены
- `-v` — подробно описывать действие или отсутствие действия для каждого файла

Группа указывает, для каких пользователей нужно применять права:
- `u` — владелец файла
- `g` — группа файла
- `o` — другие пользователи
- `a` — все пользователи

Действие может быть одно из трех:
- `+` — добавить определенные права
- `-` — удалить определенные права
- `=` — установить определенные права

Режим — собственно права доступа:
- `r` — чтение файла или содержимого каталога
- `w` — запись в файл или в каталог
- `x` — выполнение файла или чтение содержимого каталога
- `s` — установленные атрибуты `SUID` или `SGID` позволяют запускать файл на выполнение с правами
владельца файла или группы соответственно
- `t` — устанавливая sticky bit для каталога, мы защищаем файлы в нем; удалить файл в такой 
директории может только владелец этого файла

Команда никогда не изменяет права на символьные ссылки. Однако, для каждой символьной ссылки, 
заданной в командной строке, `chmod` изменяет права доступа связанного с ней файла.

Примеры использования:
- `chmod g+rx data.txt` - установить для группы право на чтение и выполнениеКопировать
- `chmod go-rwx data.txt` - забрать все права у группы и остальных пользователейКопировать
- `chmod a+rwx data.txt` - установить полный доступ всем пользователямКопировать
- `chmod u=rwx,g+w,go-x script.sh` Копировать
- `chmod u+s backup.sh` - установить для файла SUIDКопировать
- `chmod g+s backup.sh` - установить для файла SGIDКопировать
- `chmod -R u-s,g-s /home/dev` - рекурсивно удалить SUID и SGIDКопировать
- `chmod +t /home/dev` - установить sticky-бит на каталогКопировать

Использование команды в числовом виде:
- `0` - никаких прав  
- `1` - только выполнение  
- `2` - только запись  
- `3` - выполнение и запись (1 + 2)  
- `4` - только чтение  
- `5` - чтение и выполнение (1 + 4)  
- `6` - чтение и запись (2 + 4)  
- `7` - чтение, запись и выполнение (1 + 2 + 4)
